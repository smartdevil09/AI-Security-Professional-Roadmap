# AI-Security-Professional-Roadmap

## Introduction & Prerequisites

### What This Roadmap Covers

This comprehensive roadmap covers **AI Security** from ground zero to expert level. Even if you don't know what AI, ML, LLM, or agentic AI means, this path will guide you through everything.

**What You'll Learn:**
- How AI and Machine Learning actually work (from basics)
- What Large Language Models (LLMs) are and their vulnerabilities
- How to attack and defend AI systems
- How to conduct red teaming exercises
- How to secure AI supply chains
- How to build enterprise-grade AI security
- How to create production-ready security tools

**What You Can Build:**
- Hands-on attack demonstrations
- Security assessment tools
- Red teaming frameworks
- Threat modeling documents

### Prerequisites

**Minimum Requirements:**
- Basic Linux command knowledge (ls, cd, mkdir, etc.)
- Familiarity with one programming language (Python, Go, or similar)
- 2-4 hours per week 
- A laptop/computer with internet

**Nice to Have:**
- Basic cybersecurity knowledge
- Understanding of APIs and web concepts
- Familiarity with DevOps/CI-CD pipelines
